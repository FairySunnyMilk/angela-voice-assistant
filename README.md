# Анджелла 🎙️

![License](https://img.shields.io/badge/license-Apache--2.0-blue)
![Python](https://img.shields.io/badge/Python-3.14%2B-blueviolet)
![Local](https://img.shields.io/badge/100%25-локально-success)

Локальный голосовой ассистент на русском языке: слышит, думает и отвечает голосом — **не отправляя ни слова в облако**.

- 🗣 Распознавание речи — офлайн, [Vosk](https://alphacephei.com/vosk/)
- 🔊 Озвучка — офлайн, [Silero TTS](https://github.com/snakers4/silero-models)
- 🧠 «Мозг» — локальная LLM через [Ollama](https://ollama.com/)
- 💻 Разрабатывается и работает на ноутбуке 2011 года — слабое железо не приговор

## Возможности

| Что сказать | Что будет |
|---|---|
| «Анджелла» | пробуждение — дальше слушает команду |
| «Который час» | скажет текущее время |
| «Поставь таймер на пять минут» | запустит таймер |
| «Включи музыку» / «пауза» / «следующий трек» | управление плеером |
| «Расскажи про ...» | найдёт статью в Википедии и прочитает |
| «Какая погода» | прогноз погоды |
| «Найди в интернете ...» | откроет поиск |
| «Привет» / «расскажи шутку» / «как дела» | small talk — десятки заготовленных ответов |
| всё остальное | ответит локальная LLM — свободный разговор |

Забавный факт: Vosk коверкает имя по-разному, поэтому Анджелла отзывается не только на «Анджеллу», но и на «моя лапочка», «да ласточка» и ещё два десятка вариаций — полный список в [`config.py`](src/angela_voice_assistant/config.py) 😄

## Как это работает

```
микрофон → Vosk (речь → текст, офлайн)
        → маршрутизатор команд (нечёткое сравнение)
        → навык (музыка / таймер / вики / погода)  или  локальная LLM (Ollama)
        → Silero TTS (текст → голос, офлайн) → колонки
```

## Установка

**Понадобится:** микрофон, Linux, [uv](https://docs.astral.sh/uv/) и [Ollama](https://ollama.com/download).

```bash
# 1. Клонируй репозиторий и установи зависимости
git clone https://github.com/FairySunnyMilk/angela-voice-assistant.git
cd angela-voice-assistant
uv sync

# 2. Скачай LLM для Ollama (~1 ГБ)
ollama pull lakomoor/vikhr-llama-3.2-1b-instruct:1b

# 3. Скачай модель распознавания речи
#    https://alphacephei.com/vosk/models → vosk-model-small-ru-0.22
#    Распакуй архив в папку models/, чтобы получился путь:
#    models/vosk-model-small-ru-0.22/

# 4. Запусти
uv run angela-voice-assistant
```

> 💡 Модель LLM всего на 1 млрд параметров — в квантованном виде она умещается даже в скромный объём ОЗУ, поэтому ассистент живёт целиком на слабом ПК.
